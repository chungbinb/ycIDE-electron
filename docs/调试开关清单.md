# 调试开关清单

ycIDE 渲染进程内置了若干运行时调试开关，用于排查编辑器交互和流程线问题。开发模式（`npm run dev`）下全部默认开启；打包后的生产环境默认关闭，可按下述方式手动开启。

## 开关列表

| 开关 | 作用 | 主要涉及文件 |
|------|------|--------------|
| `__EYC_ACTION_DEBUG__` | 记录 IDE 全局用户操作（点击、按键、输入、剪贴板等），批量发送到主进程日志 | `src/renderer/src/utils/ideActionLogger.ts`、`EycTableEditor.tsx` |
| `__EYC_FLOW_PASTE_DEBUG__` | 输出流程线解析与粘贴处理的调试信息（`console.debug` 带 `[EYC_FLOW_DEBUG]` 前缀），同时也会启用操作日志 | `eycFormat.ts`、`useEditorInteractionHandlers.ts`、`EycTableEditor.tsx`、`ideActionLogger.ts` |

## 开启方式（生产环境）

在渲染进程 DevTools 控制台执行其一：

```js
// 方式一：全局变量（当前会话有效）
globalThis.__EYC_FLOW_PASTE_DEBUG__ = true

// 方式二：localStorage（重启后仍有效）
localStorage.setItem('__EYC_FLOW_PASTE_DEBUG__', '1')
```

关闭：

```js
delete globalThis.__EYC_FLOW_PASTE_DEBUG__
localStorage.removeItem('__EYC_FLOW_PASTE_DEBUG__')
```

## 注意事项

- 操作日志（`__EYC_ACTION_DEBUG__`）会采集输入值预览和剪贴板预览（截断到 120 字符），仅用于本地排查，请勿在含敏感信息的项目上长期开启。
- 新增调试开关时请同步更新本清单，并沿用 `__EYC_XXX_DEBUG__` 命名约定（全局变量 + localStorage 双通道，生产默认关闭）。
