# 可编辑 EUI 窗口示例

先按 [支持库说明](../../lib/eui/README.md) 准备 Windows x64 SDK 和 MSVC，再在 IDE 打开 [EUI窗口示例.epp](EUI窗口示例.epp)。

1. 在窗口设计器调整控件位置、尺寸和属性；双击按钮编辑事件。
2. 保存并编译/运行。创建事件会更新标签，输入文本后点击“应用属性”会读取编辑框内容。
3. “切换浅深色”改变程序自身主题；它与 IDE 当前主题无关。
4. “打开非模态窗口”使用显式非模态 `载入`；“异步模态窗口”使用 `EUI显示窗口`，调用立即返回。
5. 关闭第二窗口后可再次打开；子窗口的关闭按钮执行 `销毁`。
6. 主窗口和子窗口的标题栏、边框与窗口按钮都是 EUI 自绘，不再显示 Windows 原生装饰。标题区域可拖动、双击最大化；边缘可缩放，自绘窗口按钮支持键盘操作。

示例图片内嵌在窗体中，复制项目到其他目录仍可编译；无需依赖独立 P0 示例目录。编译结果位于 `output\windows\x64`，运行时不要删除其 `assets`。

当前是 Windows 实验链路，尚无系统读屏和断点调试；不能当成 Linux/macOS 或正式分发验收。设计器为布局模拟，使用原生预览检查实际效果；预览不执行用户事件代码。
