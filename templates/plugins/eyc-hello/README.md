# 易语言插件模板

用「插件开发支持库」（`lib/ycplugin`）写 ycIDE 插件。

1. 在 IDE 里打开 `插件.epp`，在「支持库配置」里勾选 **插件开发支持库**。
2. 编译（控制台程序），把生成的 exe 改名为 `plugin.exe` 放到本目录（与 `plugin.json` 同级）。
3. 开发时设置环境变量 `YCIDE_EXTRA_PLUGIN_DIRS` 指向本目录的父目录，重新编译后 IDE 会自动重新加载插件。

注意：

- 程序里**不要用「标准输出」**，标准输出是和 IDE 通信的通道，写进去会打乱协议；要显示信息用「插件_显示消息」「插件_输出」。
- 可执行文件插件以原生程序运行，安装时 IDE 会提示用户「不受权限限制」；调用 IDE 能力（如读取文档）仍需在 `permissions` 里申请。

完整说明见 `docs/插件开发指南.md`。
